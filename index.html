CASE 01 · BUILD

Foreclosure Intelligence Scraper

Loom walkthrough coming soon
N8NValuation APIScoring

Problem

County foreclosure listings are scattered and slow to check by hand, and paying to value every property again and again burns budget.

What I built

  • An N8N scraper that pulls county foreclosure listings daily
  • Values every property through an automated valuation API
  • Scores deals by price-to-value ratio and days until auction
  • Skips duplicate paid lookups

Result

Live across 4 NJ counties: Burlington, Camden, Gloucester and Salem. The team starts each day with a ranked list instead of a search.

04 / How I Work

Four rules I build by.

01

Find the leak.

Start where the money escapes: leads nobody called, follow-ups that never fired, reports nobody trusts.

02

Fix the system, not the symptom.

A missed lead is rarely a people problem. I change the process so the same miss can't happen again.

03

Build for real life.

Exceptions, failures and people. Every system plans for the bad data, the API that's down and the busy day.

04

Hand over something the team can run.

Clear SOPs, readable dashboards and no black boxes. It keeps working when I'm not in the room.
